# Memory Game Dev 🎮

A Memory Game built with React and TypeScript where players test their memory skills by matching pairs of cards.

## Repository

[GitHub Repository](https://github.com/VFManoel/react-memory?utm_source=chatgpt.com)

## Features

* Match identical card pairs
* Interactive gameplay
* Restart game functionality
* Responsive design
* Smooth user experience
* Fast and simple interface

## Technologies Used

* React
* TypeScript
* HTML5
* CSS3

## Installation

Clone the repository:

```bash
git clone https://github.com/VFManoel/react-memory.git
```

Navigate to the project folder:

```bash
cd react-memory
```

Install dependencies:

```bash
npm install
```

## Running the Project

Start the development server:

```bash
npm start
```

Open in your browser:

```text
http://localhost:3000
```

## Build for Production

Create a production build:

```bash
npm run build
```

The optimized build files will be generated in the `build` folder.
